本プログラムは、フィールド上での移動速度を大幅に向上させるためのものです。徒歩およびじてんしゃのどちらの状態にも対応しており、広大なマップを短時間で移動できるようになります。

## 操作方法

| 手順 | 操作               | 備考                                         |
| :--- | :----------------- | :------------------------------------------- |
| 1    | プログラムの実行   | 実行後、即座に移動速度の変更が適用されます   |
| 2    | 徒歩での移動       | 通常よりも速いスピードで歩行が可能になります |
| 3    | じてんしゃでの移動 | 徒歩時よりもさらに高速な移動が可能になります |

## 注意事項

- プログラム実行中に「ボックス」の変更を行わないでください。セーブデータが破損する恐れがあります。
- じてんしゃでの移動時、マップの構造によっては正常に動作しない場合があります。
