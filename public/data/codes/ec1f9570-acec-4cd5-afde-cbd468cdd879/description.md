本プログラムは、フィールド上での移動速度を大幅に向上させるためのものです。徒歩およびじてんしゃのどちらの状態にも対応しており、広大なマップを短時間で移動できるようになります。

## 操作方法

本プログラムを起動することで、移動速度が以下のように変化します。

| 移動手段 | 効果                                         |
| :------- | :------------------------------------------- |
| 徒歩     | 通常よりも速いスピードで歩行が可能になります |
| 自転車  | 徒歩時よりもさらに高速な移動が可能になります |

## 注意事項

プログラムの動作を安定させるため、以下の点に十分ご注意ください。

| 項目         | 内容                                                                     |
| :----------- | :----------------------------------------------------------------------- |
| ボックス操作 | プログラム実行中に「ボックス」の変更を行わないでください                 |
| リスク       | 上記に反してボックスを変更した場合、セーブデータが破損する恐れがあります |

非常に強力な移動手段ですが、データ保護のためボックス操作の制限は必ず守って使用してください。
